# Легенды «от местных» — черновик с kharkovforum

Источник: [Легенды Харькова](https://www.kharkovforum.com/threads/lehendy-khar-kova.73438/)

## Что смотреть

- **`CANDIDATES.md`** — только **заголовок + текст** (удобно читать и отбирать)
- **`candidates.json`** — тот же набор в формате сайта (`keep`, тип `от местных` и т.д.)

Связанные сюжеты сведены в одну запись с блоками **«А ещё одна версия говорит об этом иначе:»** (например, крест с Благовещенского: в реку / мусоровоз / согнутый крест).

Тексты поданы как устная молва: «ходят слухи», «местные говорили», «я когда-то слышал»…

## Как отобрать

В `candidates.json` у нужных:

```json
"keep": true
```

Когда скажете — добавим на сайт с типом **от местных**.
