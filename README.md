# Легенды Харькова

Городские байки, слухи и предания о Харькове — из книги Савелия Цыпина и из уст харьковчан.

Сайт: [khlegends.com](https://khlegends.com)

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Деплой (Vercel)

1. Подключите этот репозиторий к Vercel.
2. В Environment Variables задайте:

```
NEXT_PUBLIC_SITE_URL=https://khlegends.com
```

3. Привяжите домен `khlegends.com` в Vercel → Domains и пропишите DNS у регистратора.
